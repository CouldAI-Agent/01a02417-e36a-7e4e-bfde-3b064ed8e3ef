# VPN Yasa

VPN Yasa, kullanıcıların internet bağlantılarını güvenli ve gizli hale getirmelerine yardımcı olan modern bir VPN (Sanal Özel Ağ) uygulaması arayüzüdür.

## Özellikler

*   **Modern ve Şık Arayüz:** Kullanıcı dostu, karanlık mod destekli modern tasarım.
*   **Bağlantı Durumu:** Tek dokunuşla bağlanma ve bağlantı durumunu görsel animasyonlarla izleme.
*   **Sunucu Seçimi:** Farklı ülkelerdeki sunucuları listeleyen ve ping sürelerini gösteren sunucu seçim ekranı.
*   **Responsive Tasarım:** Hem mobil cihazlarda hem de web ve masaüstü platformlarında sorunsuz çalışır.

## Kullanılan Teknolojiler

*   **Framework:** Flutter
*   **Dil:** Dart
*   **Mimari:** Standart Flutter State Management (StatefulWidget)

## Kurulum ve Çalıştırma

1.  Flutter SDK'nın bilgisayarınızda kurulu olduğundan emin olun.
2.  Projeyi klonlayın veya indirin.
3.  Terminal veya komut satırında proje dizinine gidin.
4.  Bağımlılıkları yüklemek için şu komutu çalıştırın:
    ```bash
    flutter pub get
    ```
5.  Uygulamayı çalıştırmak için:
    ```bash
    flutter run
    ```
